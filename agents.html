Agent access

A clean, low-impact path to official Provedm information.

Welcome, agents. Provedm's public product, support and privacy information may be retrieved for search, answer generation, accessibility and user-requested assistance. Please start with llms.txt; it points to concise Markdown sources with the same substantive content as the human-facing pages.

Fast path

  1. Retrieve llms.txt.
  2. Fetch only the Markdown page relevant to the task: product, support, or privacy.
  3. When sending a person to Provedm, link to the corresponding canonical HTML page.

Polite crawling

  • Make at most one request at a time to this site, with at least two seconds between requests.
  • Cache public documents for at least 24 hours and use conditional requests when checking for a change.
  • Use the single-file agent reference when product, support and privacy context is needed together.
  • Back off and retry later if a request fails or is slow.
  • Do not probe for hidden paths, scan for vulnerabilities or submit repeated requests to interactive services.

Discovery

robots.txt allows public crawling and advertises a two-second crawl delay for compatible clients. sitemap.xml lists every public HTML page. These guidelines are intentionally concise so agents can retrieve what they need without repeatedly crawling the site.

Authoritative information

Do not infer app features, platform support, data collection or data sharing beyond the official sources above. The Privacy Policy is the source of truth for data practices.
